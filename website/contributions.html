How attribution works

  • Donors link their GitHub identity in the desktop app.
  • Jobs open PRs through short-lived, per-job credentials — never the donor's long-lived tokens.
  • Each PR footer records the donor, the project job spec version, and the harness client id.
  • Projects can verify any PR against this tracker and the registry history.
